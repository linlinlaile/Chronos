# 刷课时脚本

自动刷杭州市专业技术人员继续教育学时的 Python 脚本，基于 Playwright 控制浏览器。

## 功能

- **自动登录等待**：脚本启动后打开浏览器，未登录时停在登录界面等待手动登录（登录一次即可，浏览器常驻不退出，避免反复登录）
- **自动选课类别**：读取「学时管理系统」的「现已完成学时」数据，对比年度要求（专业课程 60 / 行业公需 30 / 一般公需 30 学时），自动选择**缺口最大的类别**去学
- **课程队列选课**：首次按类别扫描第 1～5 页，记录全部课程的页码、位置和时长，之后按时长从低到高继续学习
- **学时性价比选课**：课程页面提供可计学时时，按当前缺口计算总播放时长最短的课程组合；无法读取学时时兼容旧的时长排序
- **自动播放**：进入课程 → 点击「立即学习」→ 点击「Play Video」开始播放
- **自动循环**：视频播放完成后记录课程并进入队列下一门；完成弹框出现时自动选择“否”，直到该类别学时达标；所有类别达标后停止，浏览器窗口保持打开
- **自动处理弹框**：播放过程中出现确认弹框自动点「确定」
- **避免重复学习**：视频正常播放完成后记录课程标识到 `learned_courses.json`，后续选课自动排除已完成课程
- **完成课程确认**：出现“获得学分，是否继续学习”提示时自动选择“否”，关闭当前课程并寻找下一门

## 环境要求

- Python 3.10+
- 安装依赖，并确保电脑已经安装 Google Chrome：

```bash
pip install -r requirements.txt
```

## 使用

```bash
python -u main.py
```

启动后：

1. 弹出浏览器窗口，跳转到杭州人事学习平台课程页
2. 若未登录，在浏览器中点击「学员登录」完成登录（浙江政务服务网 SSO）
3. 脚本检测到登录后自动开始循环刷课
4. 按 `Ctrl+C` 停止

> 注意：必须用 `-u` 参数运行，否则输出会被缓冲看不到进度。

## 配置

所有配置在 [config.py](config.py)：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `TARGET_URL` | 课程列表页地址 | `https://learning.hzrs.hangzhou.gov.cn/#/Course` |
| `CREDIT_SYSTEM_URL` | 学时管理系统首页 | `https://learning.hzrs.hangzhou.gov.cn/#/backIndex` |
| `CREDIT_REQUIREMENTS` | 各类别年度学时要求 | 专业课程 60 / 行业公需 30 / 一般公需 30 |
| `TIMEOUT` | 操作超时（毫秒） | 30000 |
| `BROWSER_CHANNEL` | Playwright 启动的浏览器通道 | `chrome` |
| `CREDIT_CHECK_INTERVAL` | 刷新学时面板的课程间隔 | `5` |
| `COURSE_PAGE_END` | 首次建立课程目录的最大页码 | `5` |
| `COURSE_CATALOG_FILE` | 分类课程目录保存文件 | `course_catalog.json` |
| `CREDIT_SELECTION_MAX_CANDIDATES` | 学时组合搜索的最大候选课程数 | `80` |
| `CREDIT_HOUR_PRECISION` | 学时组合计算精度 | `0.5` |

## 登录状态持久化

登录信息保存在 `user_data/` 目录（项目专用 Chrome 用户数据目录）。

- 脚本会在本机 `127.0.0.1:9222` 查找自己之前启动的 Chrome；如果已有学习平台且已登录的页面，会直接复用该页面，不再新开浏览器。
- 第一次启用此功能时，需要关闭旧的脚本浏览器并重新运行一次，让 Chrome 带调试端口启动。手动从桌面打开、未带调试端口的 Chrome 无法被 Playwright 接管。
- Chrome 以独立进程运行，关闭运行脚本的终端不会关闭浏览器窗口；再次运行脚本会重新连接该 Chrome。

- 脚本运行期间浏览器**保持打开**，同一项目用户数据目录中的登录状态会被复用
- 浙江政务服务网 SSO 会话有时效；如果会话已过期，仍需重新登录

## 文件结构

```
刷课时脚本/
├── main.py              # 主入口，常驻循环刷课逻辑
├── config.py            # 配置文件（学时要求、URL、超时等）
├── actions.py           # 页面操作封装（选课、查询、播放、学时读取等）
├── browser/
│   └── __init__.py      # 浏览器启动、登录检测、页面导航
├── requirements.txt     # Python 依赖（playwright）
├── user_data/           # 浏览器用户数据（登录状态持久化，自动生成）
├── learned_courses.json  # 已完成课程记录（自动生成）
├── course_catalog.json   # 分类课程队列（自动生成）
└── *.png / *.html       # 调试产物（可删除）
```

## 工作流程

```
启动浏览器 → 打开课程页 → 等待登录
    → 进入学时管理系统读取学时数据
    → 计算缺口，选缺口最大的类别
    → 返回课程页选择该类别 → 查询
    → 在当前页选时长最短的课程 → 立即学习 → Play Video
    → 监听视频播放完成 → 确认完成弹框
    → 关闭播放页 → 回到学时系统重新读取
    → 循环直到所有类别达标
```

## Why

The repository mixes the active Playwright automation with an unrelated legacy Java/Spring/WebMagic project, IDE metadata, generated artifacts, and Python selection paths that are no longer called by the production entry point. This obscures the actual runtime surface, increases maintenance cost, and makes future reliability work harder to review.

## What Changes

- Remove the tracked legacy Maven/Spring/WebMagic application and associated IDE-only project metadata after confirming that the Python launcher, documentation, and tests do not reference them.
- Remove superseded Python course-selection helpers, obsolete configuration imports, and tests that exist only for those unreachable paths.
- Retain the active catalog-based, credit-efficient course selection, browser lifecycle, playback verification, dialog handling, and failure-recovery behavior without changing their external behavior.
- Update repository ignore rules and documentation so generated bytecode, runtime screenshots, browser profiles, course catalogs, and per-user learning records are not confused with maintained source.
- Preserve existing user learning state and runtime data during cleanup; removal from version control, where appropriate, must not delete a user's local files.

## Capabilities

### New Capabilities

None. This is a behavior-preserving repository cleanup and refactor.

### Modified Capabilities

None. Existing automation requirements and observable learning behavior remain unchanged.

## Impact

- Repository structure: `pom.xml`, `src/`, tracked `.idea/` metadata, generated Python bytecode, debug images, and redundant root artifacts are candidates for removal.
- Python code: `actions.py`, `main.py`, `config.py`, and `tests/` may lose unreachable helpers, imports, constants, and obsolete tests.
- Documentation and ignore rules: `README.md` and `.gitignore` will describe only the maintained Python application and separate source from runtime state.
- No dependency or public API additions are expected. The Playwright runtime, persistent Chrome profile, learned-course records, and course catalog formats remain compatible.
